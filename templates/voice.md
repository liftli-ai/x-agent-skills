# Voice file

Every Liftli writing skill reads this file before it writes, on LinkedIn and on
X. Keep it short and true. Two minutes of honest answers here beat any prompt.

Save it as `.liftli/voice.md` in a project (applies there only) or
`~/.liftli/voice.md` (applies everywhere). The `x-voice` skill can fill it in
for you from your own posts. If you already built one with the `linkedin-voice`
skill, keep it: `x-voice` only adds the "How I sound on X" section.
